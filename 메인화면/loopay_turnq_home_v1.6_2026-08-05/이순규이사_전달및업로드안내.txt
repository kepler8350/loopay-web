1. ZIP 구성
- index.html: loopay.co.kr 접속 시 처음 보이는 분할 선택 화면
- company/index.html: 루페이 주식회사 회사 홈페이지
- 회사 홈페이지 영상 안내: 턴큐 이용설명 및 매칭설명 유튜브 영상
- company/policy/terms.html: 턴큐 이용약관 v1.6 전체 내용
- company/policy/privacy.html: 턴큐 개인정보처리방침 v1.6 전체 내용
- company/policy/operations.html: 턴큐 운영정책 v1.6 전체 내용
- company/policy-docs/: 고객이 내려받을 수 있는 v1.6 Word 문서 3개
- assets/: 공통 디자인 파일
- server.js / package.json: Railway 실행 파일
- 미리보기_실행.bat: Windows에서 분할 화면을 바로 확인하는 파일

※ 배포 전 PC에서 확인하려면 `미리보기_실행.bat`을 더블 클릭하십시오.

2. 연결 주소
- https://loopay.co.kr/ → 분할 선택 화면
- 턴큐 카드 → https://tq.loopay.co.kr/
- 회사 카드 → https://loopay.co.kr/company/
- 턴큐 이용설명 영상 → https://youtu.be/zEY2jV8y4uk
- 턴큐 매칭설명 영상 → https://youtu.be/fOhIB6qJFtQ
- 회사 홈페이지 하단 → 이용약관·개인정보처리방침·운영정책

3. Railway 배포 방법
① ZIP 압축을 풉니다.
② 압축을 푼 폴더 안의 파일 전체를 Railway 연결 저장소의 최상위(root)에 올립니다.
   ※ 바깥 폴더를 한 번 더 중첩하지 말고 package.json과 index.html이 저장소 최상위에 있어야 합니다.
③ Railway의 Start Command는 비워 두거나 `npm start`로 설정합니다.
④ 배포 완료 후 Railway Custom Domain에 loopay.co.kr을 연결합니다.
⑤ DNS 업체가 안내한 CNAME/TXT 레코드를 정확히 등록하고 SSL 발급을 기다립니다.
⑥ 기존에 설정한 URL 프레임 전달(주소 숨김 방식)이 있다면 해제합니다.
⑦ HTTP 접속이 HTTPS로 자동 전환되는지 확인합니다.

4. 매우 중요한 DNS 주의사항
- loopay@loopay.co.kr 전자우편을 계속 사용하려면 기존 MX, SPF, DKIM 레코드를 삭제하지 마십시오.
- 홈페이지 연결에 필요한 CNAME/TXT만 Railway 안내값에 따라 수정합니다.
- 확신이 없을 때에는 DNS 전체를 교체하지 말고, 호스팅 담당자와 현재 레코드를 함께 확인하십시오.

5. 배포 후 확인 목록

[ ] PC와 휴대전화에서 화면이 깨지지 않는가
[ ] 이용약관·개인정보처리방침·운영정책에 v1.6이 표시되는가
